# FocusFlow

Plan smarter. Study better.

A student productivity and study-planning web app (UI/UX mini project).

## Screens
Landing, Login/Sign up, Dashboard, Tasks, Study Planner, Focus Mode, Progress, Settings.

## Run
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Structure
- `index.html` page markup
- `css/style.css` styles and theme tokens
- `js/script.js` app logic, sample data and screens
